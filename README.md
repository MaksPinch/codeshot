# CodeShot

CodeShot is a Django learning project for creating syntax-highlighted
code previews and exporting them as images.

## Requirements

- Python 3.12+

## Setup

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Run Tests

```bash
python -m pytest
```

## Run Development Server

```bash
python manage.py runserver
```
## Image export
CodeShot exports the current editor state as an image.
Supported formats:
- PNG: `GET /download/png/`
- JPG: `GET /download/jpg/`
The export endpoints use the latest valid editor state stored in the
session.
They return a file response with the correct `Content-Type` and
`Content-Disposition` headers.

## Security note

User code must not be rendered with `|safe` directly.
The preview renders HTML generated by the highlighting service.
If the highlighting implementation changes,
escaping behavior must be reviewed and covered by tests.
