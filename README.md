# CodeShot
CodeShot is a Django learning project for creating syntax-highlighted
code previews and exporting them as images.

## Requirements
- Python 3.12+

## Setup
```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```
## Run Tests
```bash
python -m pytest
```

## Run Development Server
```bash
python manage.py runserver
```
